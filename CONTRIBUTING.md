## 🤝 How to Contribute

### Reporting Issues

- Search existing issues first.
- Use the issue templates if available.
- Provide clear reproduction steps.
- Include environment details.

### Suggesting Enhancements

- Check the roadmap and existing discussions.
- Explain the use case and expected behaviour.
- Consider implementation complexity.

### Code Contributions

#### Prerequisites

- A modern web browser.
- A text editor or IDE for editing HTML, CSS, and JavaScript.

#### Development Setup

```bash
# Clone the repository
git clone https://github.com/hmlendea/text-obfuscator.git
cd text-obfuscator
```

No additional dependencies are required; the project is a static client-side web application.

#### Making Changes

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes.
4. Commit with clear and descriptive messages.
5. Push to your fork.
6. Open a Pull Request.

#### Pull Request Guidelines

- Target the `master` branch.
- Keep PRs focused and atomic.
- Revise documentation if applicable.
- Ensure the CI checks pass.

### Code Style

Follow the project's coding standards:
- Maintain consistent indentation using spaces.
- Use clear, descriptive variable and function names.
- Keep functions focused and under 30 lines where possible.
- Prefer self-explanatory code; comments only when exceptionally useful.

### Testing

No automated test suite is configured for this project. Manual testing is performed by running the application in a web browser.

### Documentation

- Revise relevant docs for changes.
- Follow the documentation style guide.
- Preview changes locally if possible.
