# Privacy and Personal Data

## 📑 Table of Contents

## 🔎 What This Document Covers

This document describes how Text Obfuscator at https://github.com/hmlendea/text-obfuscator handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 🏠 Self-Hosted Deployments

The Text Obfuscator is a client-side JavaScript tool that runs in the browser to replace characters in text with random equivalents. It is designed for developers to obfuscate text for various purposes. As a self-hosted deployment, the instance operator controls local storage, logs, backups, access controls, retention, and request handling unless the project directly controls those functions.

No data is sent from a self-hosted instance to project maintainers or external services. The tool operates entirely in the browser and does not transmit any personal data to external servers.

## 📥 Data We Handle

### Data Provided to the Application

- None. The Text Obfuscator is a client-side tool that processes text provided by the user directly in the browser. No personal data is collected, stored, or transmitted by the application.

### Data Generated or Collected by the Application

- None. The application generates obfuscated text based on user input but does not collect, store, or transmit any personal data.

### Data Received from Integrations

- None. The Text Obfuscator has no external integrations that process or receive personal data. It relies solely on the text provided by the user in the browser.

## 🧭 Processing and Use

The application processes the text provided by users for the following verified function:
- Character obfuscation — replacing characters in text with random Unicode equivalents to make the text harder to read or interpret.

## 🗄️ Storage, Retention, and Deletion

- No data is stored locally by the application. The obfuscated text is displayed in the browser interface and is not persisted anywhere.
- No retention or deletion of personal data is required as no personal data is collected.
- Since no personal data is handled, there are no retention policies or deletion procedures to describe.

## ⚙️ User Controls and Requests

No user controls or request procedures are available for this application. The tool is designed for immediate obfuscation of text provided by the user in the browser.

## 🌍 International Transfers

No data may be transferred across national or regional borders. The Text Obfuscator is a self-hosted client-side tool that operates entirely within the user's browser and does not transmit any data externally.

## 🧒 Children

The Text Obfuscator does not have any age-related behaviour or special controls for child accounts. It is intended for adult developers using the tool for text obfuscation.

## 🛡️ Data Protection and Security

The Text Obfuscator implements basic security measures for the text it processes:
- All processing occurs in the browser using client-side JavaScript.
- No sensitive data is transmitted to any external server.
- The tool uses standard web technologies (HTML, CSS, JavaScript) with no additional security infrastructure.
- Since no personal data is collected, there are no privacy protections to describe beyond the absence of data collection.
